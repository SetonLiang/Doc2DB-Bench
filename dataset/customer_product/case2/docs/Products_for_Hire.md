Transitioning to our digital media wing, the classification logic shifts to accommodate format-specific attributes. The first segment of a product's type code is 'Din' if it is a standard-definition media format. The second segment of the type code is 'Plates' if the product is a multi-disc set. An underscore character is used to separate the code's segments. So when you see a product type code reading 'Din_Plates', you know exactly what you're getting: a standard-definition, multi-disc package. Our cataloging team developed this segmented notation in collaboration with a metadata standards working group based out of the University of Michigan's School of Information, though the naming convention itself predates that partnership.
