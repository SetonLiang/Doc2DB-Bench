## A.1. COMPETITION RESULT CODES, CLASSIFICATION STANDARDS, AND PODIUM DESIGNATION CONVENTIONS FOR INTERNATIONAL SWIMMING EVENTS

The following appendix consolidates official result designations, classification protocols, and individual performance outcomes across multiple international swimming competitions. For competition result logging, a podium finish is recorded as Result Code 1. A non-podium finish is recorded as Result Code 0. Official competition results use the code 'NC' to denote any swimmer who was 'Not Classified'. These standardized codes have been adopted uniformly since the 2003 harmonization agreement between continental federations and remain in effect for all sanctioned meets.

| Result Code | Description | Application Scope |
|---|---|---|
| 1 | Podium Finish (Gold, Silver, Bronze) | All FINA-sanctioned and regional championship events |
| 0 | Non-Podium Finish | All FINA-sanctioned and regional championship events |
| NC | Not Classified | Disqualification, withdrawal, or administrative exclusion |

The classification framework above governs the recording of outcomes in the official results database maintained by the International Swimming Statistics Bureau, which was established in Geneva in 1997 and currently archives over 2.4 million individual race entries.
